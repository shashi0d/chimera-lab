# R1 stream notes

Each stream writes its notes and decisions here; only the lead edits BUILD_LOG.md, DECISIONS.md, TASKSHEET.md and
ROADMAP.md, and merges these notes at the end.

- `api_notes.md`: Stream A (backend/, branch r1-api)
- `ui_notes.md`: Stream B (frontend/, branch r1-ui)
- `docs_notes.md`: Stream C (docs/submission/, branch r1-docs)
- `deploy_checklist.md`: Stream A (host requirements and comparison)

The contract is `docs/api_contract.md`; the fixtures are `docs/api_fixtures/` (generated by
`scripts/r1_make_fixtures.py` from the S5 runs).
